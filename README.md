# MEDENZA '27 Attendance Register

Vite + React attendance dashboard hosted with GitHub Pages. Meeting dates and attendance are saved in the current browser with `localStorage`; JSON backup import/export is available in the app.

## Deploy

The repository is configured for GitHub Pages. Run **Actions → Deploy attendance dashboard → Run workflow** to publish.

Attendance remains on the device/browser where it is entered. Export a JSON backup to move it to another browser or device.
